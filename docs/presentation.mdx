## System architecture

It is a (classicial) two-level architecture, an ETL pipeline

Why a two-level architecture and not an independent data mart architecture, or a lakehouse?

A single data warehouse at the storage area means that all front-end tools access from one centralized source that is the storage. Centralization can be troublesome. It is less project-oriented. However, it is simple, good for now. (Also I can't think of good contextual reasons to make it more robust). (reference: slides CO4031 DW-DSS - Chapter 2 - DW-Basic Issues, page 7, adapted from Strange (1997))

Our architecture has four layers:

1. Source data systems
2. Data staging area
3. Data storage area
4. Front-end
